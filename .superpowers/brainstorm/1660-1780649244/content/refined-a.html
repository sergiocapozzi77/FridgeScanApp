Sort UX — Two recommended approaches

Since it's just 2 modes (A-Z and by expiry), here are the options:

Option 1: Toggle Button

Single button that cycles between modes. The label updates to show current state.

A↕ZA-Z
→
📅Expiry
→
A↕ZA-Z

Tapping the same button cycles: A-Z → Expiry → A-Z → ...

Pros

  • Fast — one tap to switch
  • No popups or menus
  • Smallest footprint

Cons

  • Not obvious there are 2 modes
  • Requires memorizing what each icon means

Option 2: Segmented Chip

The sort button opens a small animated picker showing both options side by side. User taps one to select.

A↕ZSort

↓ on tap, expands inline:

A-Z
By expiry

Pros

  • Shows both options clearly
  • No guesswork for the user
  • Satisfying micro-animation

Cons

  • Two taps to change sort (open picker, tap option)
  • Takes more vertical space when expanded

Search Expansion

The Search pill animates horizontally to reveal an Entry field — similar to how the current header search button focuses the autocomplete. When tapped, the pill expands with a spring animation into a full-width search bar, pushing filter/sort pills to the right or onto a second row.

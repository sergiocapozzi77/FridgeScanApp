Key Design Decisions

🎨 Color System

Deep navy background (#0D1023), tonal purple accents, softer reds/ambers for expiry states. No flat dark rectangles.

🃏 Product Cards

20dp corner radius, tonal surfaces (#171A35), category icon containers, status chips instead of badges, kebab menu instead of edit button.

📂 Section Headers

Section title + item count with "Show all" option. More breathing room between categories.

📷 Floating Action Button

Large purple tonal FAB with barcode icon. The primary scan action.

🧭 Bottom Navigation

Material 3 Navigation Bar with pill-shaped active indicator. Taller, more spacious.

➕ Add Item Section

Full-width tonal card with + button, "Add item" label, and chevron arrow. Replaces the input field approach.

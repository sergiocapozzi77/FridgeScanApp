How should ingredients be arranged?

This shapes the entire layout direction. Pick the arrangement style you prefer.

A

Vertical Checklist

Each ingredient is a full-width row with a check icon. Clean scanning, easy tapping, classic shopping-list feel.

  • ✅ Best for long ingredient lists (scroll vertically)
  • ✅ Large touch targets (easy to tap)
  • ✅ Can show quantity alongside ingredient name
B

Chip Grid

Ingredients as compact chips/tags that wrap in a flex layout. Compact, visual, modern Material 3 feel.

  • ✅ Space-efficient — fits more above the fold
  • ✅ Modern chip aesthetic (like filter chips)
  • ✅ Tapping chip fills it with strikethrough effect
C

Mini Cards / Tiles

Each ingredient in its own small card/tile with border, image placeholder, and checkmark overlay.

  • ✅ Most visually separated — each in its own container
  • ✅ Can expand to show notes/substitutions
  • ✅ Strongest visual hierarchy

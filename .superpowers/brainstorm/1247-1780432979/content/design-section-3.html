Tap behavior, state transitions, and edge cases

Ingredient tap interaction

State Circle Text Opacity
Unchecked (default) Hollow ring, BorderColor #CCCCDD Normal, #CCCCDD 1.0
Checked (tapped) Filled, BackgroundColor #CCCCDD, shows ✓ Strikethrough, #8888AA 0.5

Method steps

Static numbered badges — no tap interaction needed. The step number badge uses #1E1E3A background (action surface token) with bold #CCCCDD text.

IngredientItem model (final)

public partial class IngredientItem : ObservableObject
{
[ObservableProperty]
private string name;

[ObservableProperty]
[AlsoNotifyChangeFor(nameof(TextColor), nameof(Opacity))]
private bool isChecked;

public TextDecorations TextDecorations
=> IsChecked ? TextDecorations.Strikethrough : TextDecorations.None;
public double Opacity
=> IsChecked ? 0.5 : 1.0;
public Color TextColor
=> IsChecked ? Color.FromArgb("#8888AA") : Color.FromArgb("#CCCCDD");
}

Numbering method steps in XAML

We'll add an IndexValueConverter that returns the item's index + 1. The step number badge binds via this converter:

// IndexValueConverter.cs
public class IndexValueConverter : IValueConverter
{
public object Convert(object value, Type targetType, object parameter, CultureInfo culture)
=> CollectionView.GetIndex(value as BindableObject) + 1;
}

Edge cases handled

  • Empty ingredients — card still shows (with title), collection is empty. Handled by existing flow.
  • Very long ingredient name — wraps to next line, circle stays aligned top-center (not center).
  • Many ingredients (scroll) — CollectionView inside ScrollView. We'll keep CollectionView height unconstrained (VerticalStackLayout inside ScrollView handles scrolling).
  • Persisting checked state — Not persisted. Checked state is ephemeral (per session). Reloading the page resets all ingredients to unchecked.
